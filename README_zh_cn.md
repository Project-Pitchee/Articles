# Pitchee Articles

在每一次测评中，我们会将你的声音量化为三个指标，分别是：

1. **音色分**：声音有多接近女性化。
2. **自然度**：声音有多像正常说话。
3. **平均音高**：整段录音里有效有声部分的平均音高，单位是 Hz。

我们用这三项算出一个综合分。60 分是及格线。低于 60 分，说明声音还没有达到本次测评的通过标准；达到 60 分，表示声音初步通过。

## 结论

| 你的情况 | 结果 |
| --- | --- |
| 音高、自然度、音色分都高 | 可能加分，最高接近或达到 100 |
| 音高够高、自然度低于 50 | 最高 30 分 |
| 音高不高于 165 Hz，自然度不低于 50 | 最高 59 分 |
| 音高不高于 165 Hz，自然度低于 50 | 最高 20 分 |
| 音高够高、自然度不低于 50、音色分低于 50 | 最高 59 分 |
| 以上都没有触发，综合分低于 60 | 三项单项及格，但本次未通过 |
| 以上都没有触发，综合分达到 60 | 初步达到及格线 |
