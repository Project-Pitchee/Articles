# Pitchee 三个分数到底说明了什么

请看三项：

1. **音色分**：声音整体有多接近女性化。
2. **自然度**：声音有多像正常说话。
3. **平均音高**：整段录音里有效有声部分的平均音高，单位是 Hz。

Pitchee 用这三项算出一个综合分。60 分是当前参考线。低于 60 分，说明这段录音还没有通过当前标准；高于 60 分，就代表声音比较Pass。

## 结论

| 你的情况 | 结果 |
| --- | --- |
| 音高、自然度、音色分都高 | 可能加分，最高接近或达到 100 |
| 音高够高、自然度低于 50 | 最高 30 分 |
| 音高不高于 165 Hz，自然度不低于 50 | 最高 59 分 |
| 音高不高于 165 Hz，自然度低于 50 | 最高 20 分 |
| 音高够高、自然度不低于 50、音色分低于 50 | 最高 59 分 |
| 以上都没有触发 | 综合分可能高于 60，也可能低于 60 |
| 没测到有效音高 | 只按音色分给结果 |
